Create tasks from Calendar

Anything on your calendar works as a task the moment you tag it. In any Google Calendar event, put #task in the title.

Daily routineReview pipeline #task @daily
Weekdays onlyMorning calls #task @weekdays
Specific daysTeam sync #task @mon,@thu
One-offFile GST #task

Requires the Calendar & Email bridge in Settings. Without it, this dashboard stays fully local and you add routines by hand.

Create tasks from Email

Forward or label an email and it lands here as a task. The subject becomes the title; directives anywhere in the subject set the schedule.

Label an emailDashboard/Task
Or mail yourselfTask: Call Mr Tan @weekdays @9am

Marking the task done here removes the label and files the thread under Dashboard/Done.

Calendar & Email bridge

Paste the Web App URL of your Google Apps Script deployment. It reads tagged calendar events and labelled emails, and syncs your completions across devices.

Not connected. The dashboard works fully offline without this.

How to set this up (about 5 minutes)
  1. Go to script.google.com and create a new project.
  2. Paste in the contents of apps-script/Code.gs from this repository.
  3. Change the SECRET at the top to a long random string.
  4. Deploy → New deployment → Web app. Execute as Me, access Anyone. Grant the Gmail and Calendar permissions it asks for.
  5. Copy the /exec URL into the field above along with the same secret, then Save & sync.

Assistant

The chat panel answers questions about your routines and can tick things off for you. It runs through a small endpoint on this site that holds the API key — the key is never in this page.

Leave the endpoint as /api/chat unless you deployed it elsewhere. Set ANTHROPIC_API_KEY (and optionally DASHBOARD_SHARED_KEY) in your Vercel project settings.
